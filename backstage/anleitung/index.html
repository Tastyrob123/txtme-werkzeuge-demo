Back to Backstage

Change, save, check, publish.

Backstage is the tool to maintain the website of txtme.social yourself: every sentence, every image, the questions, the press page, company details, the notice bar. Nothing goes live by accident: what you save waits in the draft, you see before and after, and only “Publish” changes the website. Every earlier state stays in the history.

01 · Seven moves

1

Change a sentence

Pages & texts → tap a page → tap “Change” on a sentence. Decide whether it changes only here or everywhere the sentence appears; while you type, the page below shows it in place. “Hide” takes a sentence off the page without deleting it, “Show again” brings it back. Or open “View draft”, click the sentence on the page itself: Backstage jumps to it.

2

Swap an image

On a page, under “Images on this page”: “Swap” uploads your own image (at least 900 pixels wide, up to 25 MB), “Archive” picks one from the website’s image archive. “Back” restores the original.

3

Put a line on top of every page

Notice bar: text, link, colour, size, and a date range if you like. The bar appears and disappears by itself. Preview on the right before you save.

4

Check before and after

Changes lists every place that differs from the website: before struck through, after highlighted. “View” shows the page side by side with the draft; “Take back” removes a single change.

5

Publish

The button at the bottom. Everything is set on a trial copy, checked (every page complete, every change found its place), then switched. You see the steps and then “It is online.” If some changes cannot reach the built website (for example a new question), the window says “Partly online.” and lists them; if none of them reaches it, it says “Nothing changed on the website.” If anything fails: “Not published.”, the website is unchanged, your draft is still there.

6

Bring an earlier state back

History: every release with time, note and changes. “Load into draft” puts it back as the draft, including the original state as built. Nothing goes online until you publish again.

7

If something does not work

Every error message has “What to do?” leading to the check page: it tests browser, server, data and pages, repairs the usual things with one (double) click, and explains every known error in the glossary.

02 · What stays elsewhere

Products, prices, stock and categories are managed by the txtme team in the Medusa panel. Backstage shows the catalogue for reference only. Numbers: txtme.social counts nothing, no analytics, no cookies. The chat has its own tool (chat team). Access: as long as no user exists, Backstage is open without password on this computer; an admin adds users with roles (Admin, Editor, Viewer) under Access. Some sections save more than the built website can show (new questions, shipping costs, German versions); each of these sections says so before you save.
